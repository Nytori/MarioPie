# MarioPie

1v1 local, inspirado no Pie Hard do Mario Party.

Dois jogadores no mesmo ecrã. Mesa no meio, ninguém passa para o outro lado. Apanhas a torta na tua bancada, atiras por cima da mesa e desvias-te das que vêm de volta. Acerto dá 1 ponto a quem atirou e deixa o outro atordoado uns segundos. 30 segundos, ganha quem acertar mais.
